# The Boilersuit Petition

A static, mobile-friendly application for Saahil Patel and Adam Zaidan. Open index.html to try it.

## GitHub Pages
1. Create a GitHub repository (for example `boilersuit-petition`).
2. Upload `index.html` to the repository root.
3. In the repository, open Settings → Pages. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
4. GitHub will display your public website link once deployment completes.

No build step or dependencies. Google Fonts is optional; system fonts work offline.

## Activities
- No dodges five mouse approaches or touch attempts, then allows rejection and a full-screen fiery explosion that throws page sections apart. A rebuild button restores the site.
- Yes awards a celebratory verdict with confetti.
- Worthiness scanner, zipper slider, rotating comedy pitches.
- Keyboard users can select No immediately. Reduced-motion preferences suppress explosions and confetti.

This is a humorous, unofficial petition, not an official Western application or approval system.
